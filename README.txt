CLICK & READ - ཆུ་བྱ་ཨ་རྒས་དང་ཉ་ཚུ།   (full-screen story)
=====================================================
OPEN: double-click index.html (Chrome/Edge), or upload the whole folder to SherigSpace / Netlify.

LAYOUT   10 pages. Odd pages = picture LEFT, text RIGHT. Even pages = picture RIGHT, text LEFT.
         (On phones / portrait the picture goes on top and the text below.)
         To swap a page's side, edit story.js: "layout":"L" (picture left) or "R" (picture right).

PICTURES Each page already has a drawn cartoon scene. To use your own illustration, save it in images/ as
         scene01.jpg ... scene10.jpg (or .png). It replaces the drawing automatically. Best size: 1200x1600 or square.

AUDIO    130 different words. audio/WORD-LIST.txt shows which file is which word (c001.mp3 ... c130.mp3).
         14 words were already recorded in your earlier story - those MP3s are copied in and marked "reused".
         Record the other 116 (or use Teacher Mode in the app) and save them as audio/cNNN.mp3.
         A repeated word uses the same file, so you record it only once.

BUTTONS  Read All = reads every word and turns the pages by itself.  Speed 0.5x / 0.75x / 1x.
         Arrow keys or swipe = next / previous page.   Full-screen button in the top bar.
